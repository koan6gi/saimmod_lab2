# Отчет по лабораторной работе №2.1 (LR21)
## Дисциплина: Системный анализ и имитационное моделирование (САИ)
### Тема: Создание имитационной модели сложной системы
### Вариант №5: Мини-супермаркет с раздельным обслуживанием

---

## 1. Введение и постановка задачи
Целью работы является построение концептуальной и программной имитационной модели сложной системы в соответствии с Вариантом №5:
> *«Мини-супермаркет состоит из пяти отделов. В каждом отделе одним продавцом реализуется обслуживание и расчет с покупателем».*

**Основные требования:**
1. Динамика взаимодействия представлена в виде квазипараллельного процесса.
2. Строгий запрет на использование алгоритма с постоянным временным шагом ($\Delta t$).
3. Реализация канонического алгоритма планирования событий (*Event Scheduling*) с календарем событий на приоритетной очереди (`heapq`).
4. Наличие 4 классов откликов (дискретные, непрерывные, аддитивные, финальные).
5. Использование единого датчика псевдослучайных чисел (`seed`).
6. Наличие режима детальной трассировки состояний.
7. Задание входных параметров в файле конфигурации `config.json`.

---

## 2. Архитектура программной модели

Программный комплекс организован по модульному принципу:
- `src/config.py` — загрузка параметров прогона и законов распределения.
- `src/entities.py` — структуры данных транзактов (`Customer`), ресурсов (`Department`) и событий (`Event`).
- `src/event_queue.py` — календарь будущих событий (*Future Event List, FEL*) на базе двоичной кучи.
- `src/statistics.py` — классы `ContinuousStatistic` (интегральное среднее по времени) и `DiscreteStatistic` (арифметическое среднее по выборке).
- `src/simulation.py` — имитационный движок дискретно-событийного моделирования.
- `src/simpy_model.py` — альтернативная процессная реализация на генераторах Python (`simpy.Environment`).

## 5. Выводы по Части 1 (LR21)

1. Построена концептуальная модель мини-супермаркета с 5 отделами с раздельным обслуживанием и расчетом в каждом отделе.
2. Разработан дискретно-событийный симулятор на основе календаря событий (*Event Scheduling*), обеспечивающий корректный квазипараллелизм без применения дискретного шага $\Delta t$.
3. Реализована классификация и расчет всех 4 типов откликов, включая непрерывные интегральные показатели.
4. Проведен контрольный прогон и сформирован детальный лог трассировки, подтверждающий корректность логики переходов транзактов.
